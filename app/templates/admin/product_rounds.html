Rounds

Run the same thing again on a new calendar. A round holds only dates — when each module opens, how long the free membership runs, and the day it stops selling. Everything else is the product, so there is one set of lessons and one price however many times you run it.

Whoever buys is put on whichever round is open that day, and stays on it. Somebody who joined the first run keeps the first run's dates while the third one is selling. Only the newest open round is shown on the product page, so nobody is ever asked to choose between them.
